Image Retrieval Results displays retrieved images ranked #2-#6 for each query using different methods (skipping the first result). The query image is shown in the center, with RELSIM (Ours) results on the left (most similar closest to query) and comparison method results on the right (most similar closest to query).
All images are displayed from their original URLs. Images with inactive URLs will be automatically hidden. Click on any image to view it in full size in a new tab.
